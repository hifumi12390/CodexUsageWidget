# Codex Usage Widget

Windows向けの小型デスクトップウィジェット v1.4.1。5h / Weekの使用率または残量とReset時刻、Codex Credits残高、OpenAIの稼働状況を表示します。

v1.4.1は下記GitHub Releaseからダウンロードできます。

## Codex追従モード

右クリック／⋯またはトレイのメニューから「Codexに追従（左下・影なし）」をONにします。初期値はOFFです。Codexが表示されている間は、左下のプロフィール欄から約48 DIP上へウィジェットを重ねます。Codexの位置・サイズに約100ms間隔で追従し、最小化・終了・別の仮想デスクトップでは隠れます。別アプリに切り替えてもCodexが表示されていれば残り、Codexを覆うウィンドウの下に隠れます。最前面へ固定しません。ウィジェット操作中や設定メニューを開いている間は操作を継続できます。

追従中は外側の影を無効にし、幅に余裕がある場合は見出しにFOLLOWを表示します。ドラッグ移動は無効、端からのリサイズは可能です。通常表示と追従表示の幅・高さを別々に保存し、OFFへ戻すと通常表示の位置・サイズ・最前面設定を復元します。追従中は常時最前面の設定を変更できません。「ウィジェットを隠す」で手動非表示にした場合は、トレイの「ウィジェットを表示」で追従を再開します。Codexが前面にない間もトレイから追従をOFFにできます。追従中の初期幅は220 DIP、最小幅は200 DIPです。旧版の280 DIP設定は初回移行時に220 DIPへ縮めます。幅260 DIP未満では見出しの装飾と余白を減らします。

Codex本体への埋め込みではなく別ウィンドウの重ね表示です。サイドバーの内容を押し上げたり幅を自動判定したりはしません。サイドバーを閉じた場合は本文と重なります。下端を基準にするため、追従中の折りたたみ展開は上方向へ広がります。小さいホストウィンドウでは大きさを制限してスクロールし、最小サイズも収まらない場合は隠れます。

追従先はCodexのインストール場所・実行ファイル名・ウィンドウクラスから判定します。現行のWindows Store版（実行ファイル名ChatGPT.exe）とOpenAI/Codex配下のデスクトップ版が対象です。名称や配布構成が変わった場合は対応が必要です。画面の文字・会話・認証情報は読まず、Codex本体のファイルやウィンドウ構造を変更しません。

## 起動

最新版は [GitHub Release v1.4.1](https://github.com/hifumi12390/CodexUsageWidget/releases/tag/v1.4.1) の `CodexUsageWidget-1.4.1-win-x64.zip` です。旧版が起動中の場合は×で閉じてから起動してください。設定は引き継ぎます。

ZIPを任意のフォルダーへ展開して `CodexUsageWidget.exe` を起動してください。Windows x64向けのポータブル版で、.NET runtimeは同梱されています。インストーラーや管理者権限は不要です。ビルド時の出力先は `dist/v1.4.1-win-x64/` です。

`CodexUsageWidget.exe` をダブルクリックしてください。インストール・管理者権限・.NETの別途インストールは不要です。Windows起動時の自動起動は追加しません。終了は右上の×、右クリックメニュー、またはAlt+F4です。二重起動は抑止します。

- 対象: Windows 10/11 x64。Windows 11 22H2以降はOSのDesktop Acrylicを使用します。OSの透明効果設定や省電力設定により背景効果が変わります。対応しない環境ではテーマに応じた単色背景へフォールバックします。
- **ChatGPTアカウントでログイン済みのCodexが必要です。** Codex本体は配布物に同梱しません。このPCのCodex 0.153.4で動作確認しました。
- Codexの標準インストール先とPATHからcodex.exeを検出します。見つからない場合は右クリック → Codex接続 → codex.exeを選択してください。
- 認証エラーの場合はCodexでログイン状態を確認してください。アプリ独自のログインや認証設定の変更は行いません。

## 操作

- 「Codex / ChatGPT」をクリックすると公式の稼働状況を展開／折りたたみできます。開閉状態と展開時に調整した高さを保存します。横幅は開閉で変更しません。障害・性能低下のサービスは赤文字で上に表示します。
- Codex・ChatGPTを名前に含むサービス、Login、VS Code extensionのみ表示します。汎用APIやSoraなどは対象外で、対象外の障害は見出しにも反映しません。各サービスに高さ12pxの細い直近90回の観測バーを表示します。最新の結果は右端に入り、更新時に左へ流れます。緑=正常、橙=性能低下／一部障害、赤=停止、青=メンテナンス、灰色=未観測／取得失敗。バーにマウスを重ねると観測時刻と状態を確認できます。
- 正常率は行のツールチップで確認できます。取得できた観測点のうち正常だった割合であり、90日間の時間稼働率ではありません。履歴は今回の起動中に取得した最大90回分だけをメモリーに保持します。再起動前や監視開始前の期間を正常として補完しません。流れる速さはサーバー情報の更新間隔に従います。
- 展開すると一覧に合わせてウィンドウが下へ伸びます。画面下端／最大サイズを超える内容はスクロールできます。折りたたむと展開前の高さに戻ります。次に開くと前回展開時の高さを復元し、情報更新でも手動調整を維持します。公式障害情報は下部のテキストリンクから開けます。
- 右クリック／⋯ →「利用量の更新間隔」: 15秒（高速更新）／30秒／1分／5分／15分。既存設定からの移行時と初期値は5分です。短い間隔ほど問い合わせ回数が増えます。
- 「サーバー情報の更新間隔」: 1分／5分／15分。初期値1分。利用量とは別々に動作し、折りたたみ中・トレイへ隠している間も更新します。

高速更新はサーバーへの定期問い合わせによる準リアルタイム表示です。利用量のサーバー反映遅延があるため、瞬時の反映は保証しません。時計表示は毎秒更新し、実データは取得成功時に反映します。公式Status APIの現在のサービス名を表示するため、古いStatusページ画像の分類・90日履歴とは異なります。通信失敗は「取得失敗」、未知の状態は「状態不明」として扱い、停止とは判定しません。過去の値には「前回値」を付けます。

タスクバーには表示せず、タスクトレイにアイコンを表示します（Windowsの「隠れているインジケーター」に入る場合があります）。トレイの左クリックでウィジェットを再表示、右クリックで表示・非表示・更新・通知設定・設定・終了を操作します。「ウィジェットを隠す」後も更新と通知は継続します。×は従来どおりアプリ終了です。

「残量5%未満でWindows通知」は初期ONです。5h / Weekのいずれかが残り5%未満になったことを正常な取得で確認した時に通知します。5%ちょうどでは通知しません。通知済みの枠は再起動後も繰り返し通知せず、枠のReset時刻変更または残量回復後の再低下で通知を再開します。通知OFFからONに戻した場合は次の取得時に判定します。設定した間隔での取得のため即時検知ではありません。取得失敗・未取得・期限切れ値では通知しません。

Windows Shellの通知を使用します。Windowsの通知設定・応答不可・集中モードなどで表示されない場合があります。OSが受理した通知は表示の有無にかかわらず通知済みと扱います。「通知をテスト」で表示確認できます。ガラス効果もWindowsの透明効果設定や非アクティブ状態に影響されます。非対応環境は単色で動作します。

- 上部のCODEX付近をドラッグ: 移動
- ウィンドウ端 / 右下をドラッグ: リサイズ（280×180～800×900 DIP）
- 右クリック / ⋯ / Shift+F10: 設定メニュー
- ↻ / F5 / メニューの「今すぐ更新」: 手動更新。連打時の問い合わせは10秒間隔に制限
- バーを左クリック: そのバーの使用率／残量を切替。文字とバーの長さが一緒に切り替わり、5h / Week別々に保存。Tabで選択しSpace/Enterでも操作可能
- テーマ → ダークモード / ライトモード / システムと同期: 配色を切替。「システムと同期」はWindowsのアプリモードに追従
- 背景画像を選択…: ローカルPNG/JPEG/BMP/TIFFを選択。30MB以下。アプリ内コピーを保存するため元画像を移動しても表示可能
- ガラス効果（OFFで単色） / 前回の背景画像を使用: ガラスON・単色・画像を切り替え。画像未選択時は「前回の背景画像を使用」を無効表示
- 位置・サイズを戻す: 画面右上へ戻す

初期状態は5h・Week・ResetがON、Credits・常時最前面がOFF、テーマはダーク、バーは使用率表示です。既存設定は引き継ぎます。小さいサイズでは内容をスクロールできます。ResetのみONにすることも可能です。

## 数値の意味と更新

バーは**使用済み割合／残り割合を切替可能**です。残りは取得した使用率から100−使用率で計算し、0～100%に収めます。値が未取得なら残量も取得不可です。5hは300分、Weekは10080分の枠を応答内の期間から判定します。ResetはWindowsのローカルタイムゾーンで表示します。追加利用のCodex Credits残高と利用枠リセット券の枚数は別の情報です。本アプリは追加利用残高を表示し、購入やリセット券の消費は実行しません。

起動時と選択した間隔で取得します。取得完了後から次の間隔を計測し、通信の重複を防ぎます。失敗時は間隔を延ばして最大30分とし、成功後は設定した間隔に戻ります。利用量の通信は30秒、稼働状況は15秒で打ち切ります。取得は非同期で行い、UIをブロックしません。表示する次回更新秒数は失敗時の待機時間も反映します。

取得失敗時は前回値とその取得時刻を表示します。未提供の項目は「取得不可」と表示し、推測して埋めません。Reset時刻を過ぎてもサーバーの再取得が成功するまで値を0へ戻しません。取得値はメモリー上に保持し、終了後は保存しません。

## 設定の保存先

`%LOCALAPPDATA%\CodexUsageWidget\`

- `settings.json`: 位置・サイズ・表示項目・最前面・テーマ・バーごとの表示モード・背景・任意のCodexパス
- 上記設定にはガラスON/OFF、通知ON/OFF、通知済み枠のReset時刻も保存します。利用率の履歴は保存しません。
- 利用量・稼働状況の更新間隔、稼働状況欄の開閉状態、折りたたみ時と展開時の高さも保存します。
- 追従モードON/OFFと追従中の幅・高さも保存します。通常表示の位置・サイズは追従移動で上書きしません。
- `settings.json.bak`: 前回の設定バックアップ
- `background-*.png`: 読み込み時に最大幅1600pxでデコードした背景画像コピー

設定は変更後約450ms、メニュー操作時、終了時に保存します。一時ファイルから原子的に置き換え、破損時はバックアップを試します。選択した過去の画像はユーザーの判断で削除できます。現行画像はsettings.jsonのBackgroundImageを参照してください。アプリ終了後にこのフォルダーを削除すれば設定をリセットできます。

EXEの自己展開用.NETネイティブファイルは通常`%TEMP%\.net\CodexUsageWidget`配下へ展開されます。

## データ取得とセキュリティ

Codex公式App Serverのstdio JSON-RPCを利用します。各更新で `initialize` → `initialized` → `account/rateLimits/read` を呼び、専用子プロセスを終了します。認証情報はCodex自身が管理します。ウィジェットはauth.jsonを読まず、トークンを保存・表示・ログ出力しません。ローカルTCPポートも開きません。AIへのプロンプト送信・推論・タスク作成はしません。

Codex App Serverには変更の可能性があります。互換性が変わった場合はUsage.csの取得層を更新してください。APIキーのみの認証ではChatGPT利用枠を取得できません。Windowsサンドボックス内の試験では認証不可、通常ユーザー環境で成功を確認しています。

## ビルドと検証

ソースのフォルダーでPowerShellから `./Build.ps1 -Test` を実行します。.NET 10 SDKが必要です。Project内のtools/dotnetがあれば優先します。単一EXEに.NETランタイムを同梱したwin-x64パッケージをdistへ作成します。SDK更新時はランタイムの修正版も更新して再配布してください。

`--self-test <出力フォルダー>` は専用のテスト設定と合成データを使うUI・保存・失敗復旧テストです。通常起動では合成データを使用しません。`--probe <出力ファイル>` は実利用量を1回読み出す診断です（認証情報は出力しませんが利用量の個人データは出力します）。

ソースコードはこのリポジトリで管理しています。公開前の検証項目と結果は [TESTING.md](TESTING.md)、取得方式の判断は [research/DECISIONS.md](research/DECISIONS.md) を参照してください。

稼働状況は認証不要の [OpenAI Status API](https://status.openai.com/api/v2/summary.json) を使用します。`--probe-status <出力ファイル>` はこの公開APIの読み取り診断です。利用量の方式は [Codex App Server](https://learn.chatgpt.com/docs/app-server) に基づきます。通知イベントだけに依存せず、他のCodex画面での消費も定期的に再取得します。

## 制約

- 未署名の個人用配布物です。インターネット経由の配布ではWindowsが発行元不明の警告を表示することがあります。
- デスクトップの壁紙層へ埋め込む方式ではなく、通常の独立ウィンドウです。
- Windows 10の実機、複数モニター間の異なるDPI、物理マウスの操作については別途実機受入確認が必要です。
- 自動起動・アプリの自動アップデーター・Credits購入機能はありません。

参照: [Codex App Server](https://learn.chatgpt.com/docs/app-server)、[Windows DWM属性](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwmwindowattribute)
